## 🚀 Featured Projects

Here are some of my hands-on Machine Learning and Data Science projects. Each project represents something I've learned, built, and improved along the way.

### 🎬 [Movie Recommendation System](https://github.com/SirShadmehr/movie-recommendation-system)

An NLP-based content recommendation system that suggests similar movies using movie metadata, text preprocessing, vectorization, and cosine similarity.

**Technologies:** Python, Pandas, NLP, CountVectorizer, Cosine Similarity

### 🛍️ [Mall Customer Segmentation](https://github.com/SirShadmehr/mall-customer-segmentation)

A customer segmentation project using exploratory data analysis and K-Means clustering to discover customer groups based on income and spending behavior.

**Technologies:** Python, Pandas, Scikit-learn, K-Means

### 📊 [Customer Segmentation with K-Means](https://github.com/SirShadmehr/customer-segmentation-kmeans)

An unsupervised learning project exploring customer groups through data preprocessing, feature scaling, cluster selection, and evaluation.

**Technologies:** Python, Pandas, Scikit-learn, K-Means, Silhouette Score

### 💰 [Adult Income Classification](https://github.com/SirShadmehr/adult-income-classification)

A classification project focused on predicting whether an individual earns more than $50K annually, with model comparison, threshold tuning, and evaluation.

**Technologies:** Python, Pandas, Scikit-learn, Machine Learning

### 🌸 [Iris Flower Classification](https://github.com/SirShadmehr/iris-classification)

A classic classification project comparing five machine learning models. An SVM pipeline achieved **93.33% test accuracy**.

**Technologies:** Python, Scikit-learn, SVM, Machine Learning

⭐ **My Favorite Project:** Movie Recommendation System — because deciding what to watch tonight is somehow harder than training a model.
