## 🏰 The Archives — Featured Projects

Every project is another step forward in the pursuit of knowledge.

### 🎬 [Movie Recommendation System](https://github.com/SirShadmehr/movie-recommendation-system)

A content-based recommendation system that discovers similarities between movies through metadata, NLP, text preprocessing, vectorization, and cosine similarity.

**Arsenal:** Python, Pandas, NLP, CountVectorizer, Cosine Similarity

### 🛍️ [Mall Customer Segmentation](https://github.com/SirShadmehr/mall-customer-segmentation)

An unsupervised learning project using EDA and K-Means clustering to uncover hidden customer groups based on income and spending behavior.

**Arsenal:** Python, Pandas, Scikit-learn, K-Means

### 📊 [Customer Segmentation with K-Means](https://github.com/SirShadmehr/customer-segmentation-kmeans)

Exploring customer patterns through preprocessing, feature scaling, cluster selection, and evaluation.

**Arsenal:** Python, Pandas, Scikit-learn, K-Means, Silhouette Score

### 💰 [Adult Income Classification](https://github.com/SirShadmehr/adult-income-classification)

A classification project predicting whether an individual earns more than $50K annually, featuring model comparison, threshold tuning, and evaluation.

**Arsenal:** Python, Pandas, Scikit-learn, Machine Learning

### 🌸 [Iris Flower Classification](https://github.com/SirShadmehr/iris-classification)

A classic classification challenge comparing five machine learning models. An SVM pipeline achieved **93.33% test accuracy**.

**Arsenal:** Python, Scikit-learn, SVM, Machine Learning
